Methodology: evaluating Alexa-Rufus-1

Unofficial third-party web-UI evaluation of Amazon Alexa for Shopping (Rufus).

System under test

  • Name: Alexa-Rufus-1
  • Product: Alexa for Shopping / Rufus on https://www.amazon.com
  • Interface: signed-in desktop session, panel #nav-flyout-rufus, composer #rufus-text-area (maxlength=500)
  • Driver: Playwright Chromium harness in virajshoor/SWE-Alexa

Prompting & grading

  • Multiple-choice tasks use a compact “practice quiz” framing and A/B/C/D extraction.
  • GSM8K uses numeric-only answers; SimpleQA uses normalized short-string match.
  • SWE-bench Verified asks for unified diffs; empty patches grade as unresolved (0%).
  • Parallel workers reuse a cookie jar to minimize Amazon logins.

Sample sizes

  • GPQA Diamond: full 198 items
  • SWE-bench Verified: first 40 Verified instances
  • Other academic suites: balanced slices (typically 60–80) for time/accuracy tradeoff
  • Shopping-MC: 40 custom Amazon/shopping items

Limitations

  • Not affiliated with Amazon; not an official model release.
  • Not comparable 1:1 with Open LLM Leaderboard / Artificial Analysis (different harness & access).
  • MMLU-Pro slice uses ≤4 options after compaction — not the official 10-option full test protocol.
