About this evaluation

Alexa-Rufus-1 names the evaluated system: Amazon’s Alexa for Shopping assistant (Rufus) on amazon.com, not an open-weight Hugging Face model. The harness opens the Rufus panel, sends compacted prompts (composer maxlength=500), and grades replies offline. Full trajectories live in the SWE-Alexa GitHub repository.

Academic suites other than full GPQA Diamond use balanced sample slices for wall-clock vs signal. This page is the public indexable leaderboard for those results.

FAQ

What is Alexa-Rufus-1?

The system name for Amazon.com Alexa for Shopping (Rufus) as evaluated by the SWE-Alexa Playwright harness.

How did Alexa-Rufus-1 score on GPQA Diamond?

76 / 198 correct → 38.4% on the full Diamond set.

Are these official Open LLM Leaderboard scores?

No. Official boards need open weights or vendor APIs. These are unofficial web-UI results hosted on GitHub Pages.

Why is SWE-bench Verified 0%?

Live Rufus replies refused coding / GitHub patches; zero unified diffs on 40 instances.
